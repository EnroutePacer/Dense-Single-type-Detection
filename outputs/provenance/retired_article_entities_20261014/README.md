# Retired article entities

This directory preserves the non-duplicate configuration and launcher snapshots
removed from `article/` on 2026-10-14. They are historical provenance only and
are not active training entry points. Current runnable files live in the root
`configs/`, `engine/`, `tools/`, and `tests/` trees.

The move keeps `article/` limited to research logs, method notes, experiment
interpretation, and evidence indexes without discarding older reproducibility
material.
